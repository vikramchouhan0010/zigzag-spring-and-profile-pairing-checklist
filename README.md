# Zigzag Spring and Profile Pairing Checklist

A zigzag spring (wiggle wire) holds polyethylene film in a channel. It only works when the spring and the profile match, so order them as a pair.

## Before you order
- Note the profile you have or plan to buy, and the spring that suits it.
- Measure the run in metres along the structure and add an allowance for corners and overlaps.
- Check film thickness against the channel.

## Send the supplier
Profile type, run length, film thickness, quantity, delivery place.
